# VISY-F

## Requirements
 - Godot 4.6 or later
 - An OpenXR-compatible headset (e.g. Meta Quest 3/Pro preferred for best mixed reality experience)


# Launch Instructions (PCVR)

Make sure your PCVR OpenXR runtime is set up and your headset is connected (either through SteamVR, Oculus Link or other vendor-specific methods). Then, open this repository in Godot.

Simply press the "Play" button in Godot to launch the application. The application will automatically detect and connect to your OpenXR-compatible headset.
